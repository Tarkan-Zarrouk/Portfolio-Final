# Tarkan Zarrouk — Portfolio

A React + Next.js portfolio for Tarkan Zarrouk, focused on the Social Media App and machine-learning project work.

## Run locally

```bash
npm install
npm run dev
```

The page is a responsive single-page experience with smooth anchor navigation, animated transitions, responsive project previews, and links to GitHub and LinkedIn. It uses the Next.js App Router and can be deployed with `npm run build && npm run start`.
